### 🚀 What I'm building

**[GOCO](https://github.com/Thryza-creators/GOCO)** — a custom programming language, IDE, and compiler, built from the ground up (Electron.js, JavaCC, Node.js). Leading a team of 5 through a full product build: language design, a hierarchical 1-vs-1 matchmaking backend (Node.js, Sequelize, PostgreSQL), and a competitive-programming platform.
